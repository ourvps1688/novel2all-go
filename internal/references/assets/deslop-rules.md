# 去 AI 味规则 (Sprint 35)

## 检测清单
- [ ] **重复短语**: "似乎/仿佛/不禁" 等填充词出现 >3 次/段 → 删
- [ ] **完美对称**: "不仅...而且..." 句式连续出现 → 改口语化
- [ ] **抽象名词堆砌**: "体验/感受/氛围" 等抽象词连续 → 换具体动作
- [ ] **翻译腔**: "他感觉" "她意识到" → 改直接描写
- [ ] **总结性结尾**: "这一切都说明了..." → 删, 让场景自己说话

## 改写示例
- ~~林雷感到非常震惊.~~
- → 林雷愣住了, 茶杯脱手摔在地上.

- ~~夜幕降临, 整个城市笼罩在一种神秘而忧郁的氛围中.~~
- → 路灯一盏盏亮起来. 林雷裹紧外套, 加快脚步.
