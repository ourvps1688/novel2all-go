# 项目结构 (Sprint 35)

## 推荐目录结构
```
my_novel/
  创作设定.md           总设定 (类型/风格/字数)
  设定/
    文风.md           文风锚定
    世界观/           世界观设定
      地图.md
      势力.md
      历史.md
    角色/             角色设定 (可选)
  大纲/
    总纲.md           主线大纲
    第一卷/           卷纲
    细纲_第001章.md   章纲
  正文/
    第001章.md
    第002章.md
    ...
  _tracking-state.json   自动跟踪 (角色状态/伏笔)
  references/            自定义 references (可选)
```

## 创作设定.md 模板
- 作品名
- 类型
- 风格
- 主角
- 主线冲突
- 大概字数
- 更新计划

## 文风.md 模板
- 整体风格 (第一人称/第三人称; 全知视角/限制视角)
- 节奏 (短句 vs 长句; 对话占比)
- 修辞 (比喻风格; 感官层次)
- 禁忌 (不用 X 词; 不用 Y 句式)

## 大纲排布
- 总纲: 100-200 字
- 卷纲: 3000-5000 字/卷
- 章纲: 300-500 字/章
