# 短篇平台特征 (Sprint 35)

## 知乎盐言
- 字数: 8000-15000 字
- 节奏: 300 字钩子 + 1500 字反转
- 题材: 都市情感/悬疑/小人物
- 风格: 反转 + 情绪共鸣

## 番茄短篇
- 字数: 3000-8000 字
- 节奏: 极端设定开场 + 反转
- 题材: 重生/复仇/逆袭
- 风格: 情绪宣泄 + 大反转

## 七猫短篇
- 字数: 5000-12000 字
- 题材: 古言/现言/悬疑
- 风格: 强情节 + 情感线

## 故事/一刻
- 字数: 3000-8000 字
- 题材: 情感/职场/家庭
- 风格: 现实主义 + 共鸣

## 短篇特征
- 开篇 300 字必有钩子
- 中段必有 1 个反转
- 结尾情感余韵 (不散)
- 字数严格 (超字数会被砍)

## 短篇禁忌
- ~~铺垫过长~~ → 直接进入冲突
- ~~反转太弱~~ → 反转是核心
- ~~结尾太散~~ → 干脆结尾
- ~~人物太多~~ → 2-4 个角色
