# 一致性检查清单 (Sprint 35)

## 角色一致性
- [ ] 性格前后一致 (允许策略性变化)
- [ ] 口头禅/习惯动作贯穿全篇
- [ ] 重大决定符合前史铺垫
- [ ] 价值观不矛盾
- [ ] 能力成长曲线合理

## 时间线一致性
- [ ] 事件顺序无矛盾
- [ ] 时间间隔合理 (不会穿越)
- [ ] 季节/天气/时间对得上
- [ ] 角色年龄对得上
- [ ] 历史事件不冲突

## 设定一致性
- [ ] 世界观规则一致 (无自相矛盾)
- [ ] 道具功能前后一致
- [ ] 势力关系无矛盾
- [ ] 主角能力不突然改变
- [ ] 风俗/礼仪前后一致

## 关系一致性
- [ ] 角色关系前后一致
- [ ] 派系归属无矛盾
- [ ] 师徒/血缘关系对得上
- [ ] 朋友/敌人关系演变合理
- [ ] 情感线不突兀

## 常见矛盾类型
- ~~角色突然变弱~~ → 检查能力成长曲线
- ~~忘设定~~ → 用 tracking-state.json 跟踪
- ~~时间穿越~~ → 用 TimelineEvent 时间戳
- ~~前后矛盾~~ → 用 CharacterState 跟踪角色

## 工具检测
- 跑 `consistency-check` skill 自动扫描
- 输出 critical/major/minor 三级问题
- 提示"前章 vs 后章"具体矛盾点
