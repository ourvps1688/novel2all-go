# 题材趋势参考 (Sprint 35)

## 2026 网文趋势
- **系统流 + 模拟经营**: 主角经营公司/门派, 升级感来自业绩
- **重生流 + 弥补遗憾**: 重生回关键节点, 改变命运
- **穿越 + 历史大事件**: 主角参与历史, 不改变主线
- **多穿书/快穿**: 主角穿越多个副本世界
- **赛博朋克 + 古风混搭**: 现代科技 + 古代背景
- **克苏鲁 + 网文**: 不可名状 + 升级流
- **末日 + 重生**: 重生回末日爆发前
- **娱乐圈 + 反转**: 主角身份反转 + 娱乐圈日常

## 短篇趋势
- **重生复仇**: 重生回伤害前 + 反击
- **真假千金**: 身份反转 + 情感纠葛
- **穿书成反派**: 穿成原书反派 + 改变命运
- **悬疑反转**: 第一人称有限视角 + 真相揭露
- **年代文**: 重生回 70/80 年代
- **小人物逆袭**: 普通人在极端情境下爆发

## 题材选择
- **新人作者**: 选成熟套路 (重生/穿越/系统)
- **成熟作者**: 尝试混合题材 (赛博朋克 + 古风)
- **短篇**: 重生复仇 / 真假千金 (容易爆款)

## 调研方法
- 看平台热销榜 TOP 100
- 分析爆款章节首 300 字
- 总结"成功套路"
- 融合 2-3 个套路形成新题材
