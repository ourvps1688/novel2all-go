# 情绪设计参考 (Sprint 35)

## 情绪曲线
- **三幕情绪**: 焦虑 → 紧张 → 释放 (标准故事弧)
- **网文爽文情绪**: 压抑 → 反转 → 痛快 (爽点)
- **虐文情绪**: 期待 → 破灭 → 绝望 → 翻盘
- **悬疑情绪**: 好奇 → 焦虑 → 紧张 → 揭露

## 情绪类型
- **正向情绪**: 爽/痛快/感动/惊喜/温暖
- **负向情绪**: 压抑/虐心/绝望/愤怒/恐惧
- **复杂情绪**: 又爱又恨 / 既期待又焦虑 / 矛盾心理

## 情绪密度
- 网文: 短段高密度情绪波动 (爽点密集)
- 长篇: 长情绪弧 (蓄势-爆发)
- 短篇: 紧凑情绪 + 1-2 个情绪爆点

## 情绪共鸣技巧
- **具体化**: "他感到非常悲伤" → "他红了眼眶, 但没掉眼泪"
- **动作化**: "她很生气" → "她一把摔了茶杯"
- **对比化**: "我以为他会答应" → "他摇了摇头"
- **延宕**: 让情绪延后爆发 (期待感)

## 实战检查
- 每章 1-2 个情绪高点
- 情绪不要重复 (不要连续两章都是愤怒)
- 情绪要有因有果 (不是突然情绪)
- 反派也要有真实情绪 (不是工具人)
