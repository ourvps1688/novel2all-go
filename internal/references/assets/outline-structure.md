# 长篇大纲排布 (Sprint 35)

## 大纲层级
1. **总纲** (100-200 字): 故事核心冲突 + 主线结局
2. **卷纲** (3000-5000 字/卷): 每卷主线 + 核心冲突
3. **章节细纲** (300-500 字/章): 本章任务 + 关键场景 + 钩子

## 三幕结构 (长篇)
- **第一幕** (1-30 章): 主角登场 + 金手指/设定 + 第一波小高潮
- **第二幕** (31-200 章): 持续升级 + 多势力冲突 + 情感线
- **第三幕** (201-300 章): 大决战 + 真相揭露 + 终局

## 长篇套路 (网文)
- **升级流**: 主角持续升级, 每一阶段一个新地图
- **穿越/重生**: 已知未来 + 改变命运
- **系统流**: 系统任务 + 持续解锁
- **无敌流**: 主角开局巅峰, 心理战为主
- **后宫/日常**: 情感线推进, 多女主

## 章节结构 (3000 字/章)
- **开篇钩** (300 字): 上一章悬念 + 本章新冲突
- **发展** (1500-2000 字): 场景推进 + 对话/动作
- **小高潮** (500-700 字): 本章关键转折
- **章末钩** (300-500 字): 下章悬念

## 大纲反模式
- ~~流水账~~ → 每章要有"任务" (任务驱动叙事)
- ~~支线太长~~ → 支线服务主线
- ~~反派降智~~ → 反派有自己逻辑
- ~~主角万能~~ → 主角有明确失败/挫败
