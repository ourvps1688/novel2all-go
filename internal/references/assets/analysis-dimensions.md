# 拆解维度 (Sprint 35)

## 长篇拆解维度
1. **主线情节**: 核心冲突 + 主线结局
2. **支线情节**: 情感线 + 配角线 + 暗线
3. **角色塑造**: 主角弧光 + 配角功能
4. **世界观**: 设定完整性 + 势力分布
5. **伏笔结构**: 伏笔清单 + 回收节点
6. **节奏曲线**: 高潮分布 + 情绪曲线
7. **钩子设计**: 开篇钩 + 章节钩 + 情节钩
8. **去 AI 味**: 翻译腔 + AI 痕迹

## 短篇拆解维度
1. **核心冲突**: 一句话概括
2. **钩子强度**: 前 300 字评估
3. **反转设计**: 反转类型 + 铺垫
4. **情绪曲线**: 高潮 + 余韵
5. **角色深度**: 内心戏 + 行动力
6. **去 AI 味**: 翻译腔 + AI 痕迹

## 拆解 SOP
- [ ] 第 1 遍: 速读, 记录结构 (5 分钟)
- [ ] 第 2 遍: 精读 + 标注伏笔 (15 分钟)
- [ ] 第 3 遍: 评估维度 + 写报告 (30 分钟)
- [ ] 总结: 强项 + 弱项 + 改进建议
