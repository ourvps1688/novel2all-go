# 多视角审稿 (Sprint 35)

## 5 视角
1. **一致性视角**: 角色性格漂移 / 设定冲突 / 时间线硬伤
2. **文风视角**: 翻译腔 / AI 味 / 节奏拖沓 / 钩子弱
3. **人物视角**: 角色行为合理 / 对话贴脸 / 动机连贯
4. **结构视角**: 伏笔是否被收回 / 新伏笔是否埋好 / 与大纲对得上
5. **去 AI 味视角**: 重复短语 / 完美对称 / 抽象名词 / 翻译腔

## 审稿 SOP
- [ ] 第 1 遍: 文风 + 去 AI 味 (最快, 5 分钟)
- [ ] 第 2 遍: 一致性 + 人物 (中等, 15 分钟)
- [ ] 第 3 遍: 结构 + 伏笔 (最慢, 30 分钟)
- [ ] 总结: quality_score (0-100) + overall_verdict (pass/needs_revision/fail)

## 严重程度
- **critical**: 角色死亡复活 / 设定矛盾 / 时间穿越
- **major**: 性格漂移 / 翻译腔密集 / 钩子断
- **minor**: 词不达意 / 节奏略拖 / 对话略生硬

## 常见问题清单
- [ ] 角色性格前后不一致
- [ ] 时间线硬伤 (前章 vs 后章)
- [ ] 设定自相矛盾
- [ ] 翻译腔密集 (他感觉/她意识到)
- [ ] AI 味重复短语 (似乎/不禁/情不自禁)
- [ ] 伏笔忘回收
- [ ] 章末钩子断
