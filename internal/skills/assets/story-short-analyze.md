# story-short-analyze：短篇拆文

对短篇对标文进行结构化拆解，产出可在 `/story-short-write` 复用的素材。

## 拆解维度

| 维度 | 产出 |
|---|---|
| 故事核 | 一句话讲清核心反转 |
| 五维评分 | 钩子 / 节奏 / 情绪 / 反转 / 共鸣 |
| 情节节点 | 原文引用 + 情绪标记 −9 ~ +9 |
| 写作手法 | POV / 对话 / 信息差 / 物件钩子 等 11 项 |
| 爆点 6 维 | 起因 / 转折 / 揭秘 / 冲突 / 留白 / 反转 |
| 认知反转 | 读者认知变化路径 |
| 共鸣 9 层 | 人物 / 关系 / 处境 / 情绪 / 价值 / ... |

## 输出格式

```
拆文库/{短篇名}/
├── 原文/原文.txt        # 原文备份
├── 拆文报告.md          # 故事核 + 五维评分 + 爆点 6 维
├── 情节节点.md          # 8 节节点 + 情绪标记
├── 写作手法.md          # POV / 对话 / 信息差 / 物件钩子
└── _meta.json           # 结构计数（Phase 7 门控依据）
```

## 关键校验

- **故事核必须可一句话说清**——否则不算"有故事核"
- **情节节点必须原文引用**——不能脱离原文
- **情绪标记 ±9 准确**——不是"感觉好"
- **写作手法 11 项**全部覆盖（哪怕说"无显著特征"）

## 调用示例

```
用户：/story-short-analyze 拆《曾将爱意私藏》
novel2all：
  1. 问用户提供原文 txt
  2. 按 8 节切片 + 情节节点提取
  3. 聚合成五维评分 + 写作手法
  4. 写入 拆文库/曾将爱意私藏/
```
