# story-long-analyze：长篇拆文

对长篇对标书进行结构化拆解，产出可在 `/story-long-write` 复用的素材。

## 拆解维度

| 维度 | 产出 | 用于 |
|---|---|---|
| 五维评分 | 拆文报告.md | 总评 |
| 文风分析 | 文风.md | 日更前文风锚点 |
| 角色卡 | 角色/{name}.md | 借鉴人设 |
| 剧情结构 | 剧情/故事线.md | 借鉴结构 |
| 爽点密度 | 剧情/情绪模块.md | 借鉴钩子设计 |
| 节奏曲线 | 剧情/节奏.md | 控制张力 |

## 工作流

1. **输入**：用户提供对标书（正文 txt + 章节摘要）
2. **按章节切片**：调用 `chapter-extractor` role 并行处理
3. **聚合分析**：
   - 黄金三章深度拆解
   - 五维评分（钩子 / 爽点 / 节奏 / 文风 / 人设）
   - 角色卡 / 剧情结构 / 情绪模块
4. **产出文件**：
   - `拆文库/{书名}/概要.md`
   - `拆文库/{书名}/拆文报告.md`
   - `拆文库/{书名}/文风.md`
   - `拆文库/{书名}/角色/{name}.md`
   - `拆文库/{书名}/剧情/{...}.md`

## 关键原则

- **逐章原文引用 + 情绪标记**：不用"可能是"、"似乎"
- **可复用模块单独抽出**：不放在章节文件里
- **文风要可量化**：句长 / 标点 / 对话潜台词
- **五维评分有锚点**：每个分数都对应原文章节

## 输出格式示例

```
拆文库/{书名}/
├── 概要.md              # 全书概要 + 章节索引
├── 拆文报告.md           # 五维评分 + 爽点密度 + 可借鉴套路
├── 文风.md              # 句长/标点/对话潜台词/情绪节奏 + 原文锚点
├── 角色/
│   ├── 林雷.md
│   └── 霍格.md
├── 剧情/
│   ├── 故事线.md
│   ├── 节奏.md
│   └── 情绪模块.md
└── 章节/
    ├── 第1章_深度拆解.md
    └── 第1章_摘要.md
```

## 调用示例

```
用户：/story-long-analyze 拆《盘龙》
novel2all：
  1. 问用户提供原文 txt（路径 / 内容）
  2. 调用 chapter-extractor 角色按章并行拆
  3. 聚合成结构化报告
  4. 写入 拆文库/盘龙/
```
