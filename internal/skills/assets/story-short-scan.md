# story-short-scan：短篇扫榜

识别短篇市场情绪、题材、传播信号，输出"风口预警 + 可写方向"。

## 平台特点

| 平台 | 调性 | 字数偏好 |
|---|---|---|
| 知乎盐言 | 反转 / 情感 / 现实议题 | 3000-6000 |
| 番茄短篇 | 爽文 / 逆袭 / 重生 | 2000-5000 |
| 七猫短篇 | 玄幻 / 都市 / 言情 | 3000-6000 |

## 分析维度

| 维度 | 内容 |
|---|---|
| 情绪类型 | 虐 / 甜 / 治愈 / 爽 / 治愈 |
| 题材热点 | 上升 / 平稳 / 衰退 |
| 篇幅 | 字数 + 章节数 |
| 开头 | 第一句吸引力 |
| 结尾 | 反转 / 余韵 |
| 标题 | 模式 + 关键词 |
| 人设 | 主角类型分布 |
| 传播触发点 | 为什么火 |

## 关键原则

- 每个趋势标注证据强度 / 饱和风险 / 有效期
- 数据来源必须可核验
- 缺数据时用历史参考
- 不爬不登录不绕过

## 输出

```
短篇扫榜报告.md
├── 1. 平台分布
├── 2. 情绪热度
├── 3. 题材热点（top 10）
├── 4. 篇幅与结构
├── 5. 开头与结尾模式
├── 6. 标题与人设
├── 7. 风口预警（哪些方向快饱和）
├── 8. 三项可写方向
└── 9. 下次复扫时间
```
