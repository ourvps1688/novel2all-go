# story-deslop：去 AI 味

检测并清除 AI 写作痕迹。

## AI 味特征（检测目标）

### 套话类
- "在当今社会..."、"综上所述..."、"值得注意的是..."、"不可否认..."
- "这个问题很有意义..."、"让我们一起..."
- 任何"先总结再展开"的模板化结构

### 结构类
- 每段都是"总-分-总"
- 每节都用 bullet 列表
- 转折用"然而"、"但是"开头的小学生作文式

### 用词类
- 高频出现"赋能"、"抓手"、"闭环"、"链路"
- "深入贯彻"、"扎实推进"、"落地实施"
- 形容一切美好事物用"治愈系"、"氛围感"、"松弛感"

### 句式类
- 长定语 + 抽象名词（"作为一项具有重要意义的战略性举措"）
- 反复用"这"、"那"指代无主语对象
- 段尾总用"..."或"——"留白

### 内容类
- 缺乏具体感官细节（视觉 / 听觉 / 触觉 / 嗅觉 / 味觉）
- 角色动作写得像动作清单
- 对话缺乏潜台词

## 工作流

1. **扫描**：找出文中所有 AI 味特征
2. **分类**：
   - "硬伤"：套话 / 套结构 / 套路词 → 必须删
   - "可优化"：缺乏细节 / 表达模板化 → 重写
   - "可保留"：轻度 AI 味但不影响阅读 → 标记

3. **重写**：根据原意用更具体的语言替换
4. **对比**：改前 vs 改后 diff

## 关键原则

- **不要机械替换**——"值得注意的是"换成"需要看到的是"仍然是 AI 味
- **加具体细节**——"他走进房间" → "他推开吱呀作响的木门，鞋底踩过门槛上的灰"
- **保留作者风格**——如果作者本来就这样写，不要"纠正"
- **不是降 AI 检测率**——是让文本真的"像人写的"

## 检测方法

novel2all 的 story-deslop 跑两层：

1. **本地规则扫描**：
   - 套话词典（100+ 条）
   - 句长分布（AI 倾向句长均匀）
   - 段落结构（AI 倾向每段同长）
   - 高频词统计

2. **LLM 软判断**：
   - 调 LLM "以读者视角判断这段像不像人写的"
   - 列出具体问题 + 重写建议

## 输出

```
去味报告.md
├── 1. 硬伤清单（必须删）
├── 2. 优化建议（重写）
├── 3. 改前 vs 改后 diff
└── 4. AI 味评分（0-100）
```
