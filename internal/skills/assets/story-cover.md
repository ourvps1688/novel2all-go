# story-cover：封面生成

基于书名 + 题材 + 文风锚点，生成符合目标平台风格的封面 prompt。

## 工作流

1. **输入**：书名 + 题材 + 一句话简介
2. **题材分析**：
   - 男频 / 女频
   - 子题材（玄幻 / 都市 / 言情 / 历史 / ...）
   - 调性（热血 / 治愈 / 虐 / 爽）
3. **视觉风格选择**（基于 `references/cover-styles.md`）：
   - 玄幻：水墨山水 / 龙凤 / 仙人
   - 都市：城市夜景 / 高楼 / 写字楼
   - 言情：花 / 月 / 剪影 / 拥抱
   - 历史：古风人物 / 山水画
   - 科幻：未来城市 / 飞船 / 机械
4. **生成 prompt**：
   - 主体 + 配色 + 构图 + 风格关键词
   - 适配 DALL-E / Midjourney / Stable Diffusion 不同模型的语法

## 输出格式

```
封面方案/
├── 方案1_主推.md
│   ├── 书名排版
│   ├── 配色方案
│   ├── 主体描述
│   ├── 完整 prompt
│   └── 平台尺寸（起点 / 番茄 / 晋江）
└── 方案2_备选.md
```

## 关键原则

- **书名必须清晰可读**——避免艺术字过度变形
- **主视觉元素 = 核心设定**——主角 / 关键意象 / 标志场景
- **避免低俗元素**——即使题材允许
- **平台尺寸正确**：
  - 起点 / 番茄 / 七猫：宽高比 2:3（600×900）
  - 晋江：宽高比 1:1.4
  - 知乎盐言：宽高比 3:4

## 调用示例

```
用户：/story-cover 《剑道独尊》 玄幻 热血
novel2all：
  1. 分析题材（玄幻 + 热血）
  2. 输出 2-3 个封面方案 + prompt
  3. 用户选 → 调图片生成 API / 复制 prompt 手动生成
```

## 注意

novel2all v0.20 不内置图片生成 API（避免硬绑 provider）。
封面 prompt 由用户复制到 DALL-E / Midjourney / 即梦 / Liblib 等平台生成。
