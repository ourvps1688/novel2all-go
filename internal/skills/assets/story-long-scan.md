# story-long-scan：长篇扫榜

基于可核验样本识别长篇网文市场趋势，输出"题材热度 + 可写方向"。

## 数据来源（按可信度排序）

1. 用户提供的数据 / 链接（最可信）
2. 当前 LLM 内置知识（中等可信度）
3. 内置历史趋势参考 `references/genre-trends.md`（参考用）

**不允许**：爬取网站、绕过登录、伪造数据。

## 分析维度

| 维度 | 内容 |
|---|---|
| 题材分布 | 玄幻 / 都市 / 言情 / 历史 / 科幻 / 仙侠 等 |
| 新题材信号 | 出现频率上升的题材 |
| 经典题材变化 | 老题材的新写法 |
| 篇幅与更新 | 字数 / 章节数 / 更新频率 |
| 书名模式 | 高频关键词 / 句式 |
| 开头卖点 | 黄金三章的钩子类型 |

## 关键原则

- **每个样本都标注来源 URL / 采集日期 / 榜单口径 / 有效条目数**
- **不把搜索摘要或推断写成页面事实**
- **缺数据时明确标"历史假设"，不强行分析**
- **不爬不登录不绕过访问控制**

## 输出

```
扫榜报告.md
├── 1. 平台分布
├── 2. 题材热度（top 10）
├── 3. 新题材信号（上升趋势）
├── 4. 经典题材新写法
├── 5. 篇幅与更新模式
├── 6. 书名模式分析
├── 7. 开头卖点分析
├── 8. 三项可写方向（按热度 + 差异化排序）
└── 9. 下次复扫时间
```

## 调用示例

```
用户：/story-long-scan 起点中文网
novel2all：
  1. 问用户：是否有样本？没有就用历史趋势参考
  2. 分析 + 报告
  3. 输出"三项可写方向"
```
