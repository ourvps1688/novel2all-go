# story-short-write：短篇写作

短篇小说创作：情绪设计、反转构思、精修出稿。

## 短篇结构（8 节）

```
1. 起势（建立）
2. 钩子（引发好奇）
3. 转折（第一次反转）
4. 升级（矛盾加深）
5. 危机（最强张力）
6. 反转（核心揭秘）
7. 收束（情感落地）
8. 余韵（留白 / 钩尾）
```

## 情绪曲线

每节对应一个情绪峰值，整体形成"过山车"曲线。

## 工作流

1. **短篇需求确认**：平台（盐言 / 番茄 / 七猫）+ 情绪类型（虐 / 甜 / 反转 / 治愈）+ 字数（3000-8000）
2. **故事核设计**：一句话讲清核心反转
3. **8 节小节大纲**：每节情绪 + 钩子
4. **逐节写作**：保持情绪曲线
5. **精修**：去 AI 味 + 钩子强化
6. **验收**：自动结构校验 + 情绪峰值校验

## 关键校验

- **每节必须改变**：风险 / 信息 / 关系 / 资源 / 决定 / 行动 / 读者理解（至少一项）
- **不能有占位符**："此处应有XXX" → 阻断
- **导语是第一场**：正文从导语后果或新行动开始
- **结尾有余韵**：不能"完美收束"
